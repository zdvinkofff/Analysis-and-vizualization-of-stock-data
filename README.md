# Stock Market Analysis & Visualization Tool

Высокотехнологичный аналитический инструмент на Python для автоматизированного сбора, предобработки, статистического анализа временных рядов и построения интерактивных визуализаций финансовых активов.

Проект демонстрирует глубокие навыки работы с массивами финансовых данных, расчета рыночных метрик и создания кастомных инструментов для технического анализа.

---

## 🛠 Технологический стек и инструменты

*   **Язык разработки:** Python
*   **Сбор данных (Пайплайн):** yfinance API (Yahoo Finance)
*   **Обработка данных и тайм-серии:** Pandas, NumPy
*   **Статистика и математика:** SciPy
*   **Интерактивная визуализация:** Plotly (динамические графики), Matplotlib, Seaborn

---

## 🚀 Реализованный функционал и инженерные решения

1. **Automated Data Retrieval:** Разработан модуль для динамического скачивания исторических данных по любым тикерам акций (например, AAPL, MSFT, GOOGL) за настраиваемые временные промежутки.
2. **Анализ временных рядов (Time-Series Analysis):**
   - Расчет скользящих средних (Простые SMA и Экспоненциальные EMA) для сглаживания трендов.
   - Вычисление исторической волатильности активов и ежедневной доходности (Daily Returns).
   - Фильтрация рыночного шума и выявление аномальных скачков объемов торгов.
3. **Advanced Financial Visualization:** Создан пайплайн для отрисовки интерактивных японских свечей (Candlestick charts) и графиков объемов торгов (Volume charts) с помощью Plotly. Пользователь может масштабировать графики и детально изучать ценовые паттерны в браузере.

## 📦 Инструкция по локальному развертыванию

1. Клонировать репозиторий:
```bash
git clone https://github.com
cd Analysis-and-vizualization-of-stock-data
```
2. Установить зависимости:
```bash
pip install pandas numpy yfinance plotly matplotlib seaborn notebook
```
3. Запустить проект через Jupyter Notebook:
```bash
jupyter notebook
```
